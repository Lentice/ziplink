# Ziplink

Ziplink turns the active browser tab's address into a shorter link through a user-selected shortening service.

## Language

**Shortening service**:
An external provider that accepts a target URL and returns a short URL.
_Avoid_: Shorter, URL shorter

**Target URL**:
The original destination that a short URL represents.
_Avoid_: Source URL, long link

**Direct redirect**:
A short URL response that redirects immediately to its target URL without an advertising, warning, or other interstitial page.
_Avoid_: Ad-free link
